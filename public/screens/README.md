# Скриншоты для landing

Положите сюда **реальные** PNG с телефона или из симулятора (не макеты):

| Файл | Экран |
|------|--------|
| `tili-day.png` | День, сетка часов |
| `tili-week.png` | Неделя |
| `tili-month.png` | Месяц или год |
| `lumi-wish.png` | Карточка желания / колесо |

Снять автоматически (dev на :5173):

```bash
node scripts/capture-landing-screens.mjs
```

После добавления файлов пересоберите `gh-pages`.
