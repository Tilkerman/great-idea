# tili.su — что сделать на Reg.ru (простыми словами)

## Тебе — только Reg.ru и GitHub (я код и выкладку)

### Шаг 1. Reg.ru

1. Зайди на **reg.ru** → **Мои домены** → **tili.su**.
2. Открой **DNS-серверы / Управление зоной** (или «Ресурсные записи»).
3. **Удали** старые A/CNAME для `@` и `www`, если мешают (не трогай NS reg.ru, если домен на DNS Reg.ru).

4. **Добавь 4 записи типа A** (имя хоста **`@`** или пусто — «корень»):

   | Тип | Имя | Куда (значение) |
   |-----|-----|------------------|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |

4a. **Добавь 4 записи AAAA** (GitHub сейчас рекомендует вместе с A — без них проверка HTTPS иногда «висит»):

   | Тип | Имя | Куда |
   |-----|-----|------|
   | AAAA | @ | 2606:50c0:8000::153 |
   | AAAA | @ | 2606:50c0:8001::153 |
   | AAAA | @ | 2606:50c0:8002::153 |
   | AAAA | @ | 2606:50c0:8003::153 |

5. **Добавь CNAME** для www:

   | Тип | Имя | Куда |
   |-----|-----|------|
   | CNAME | www | tilkerman.github.io |

6. Сохрани. Жди **от 15 минут до суток**.

### Шаг 2. GitHub (с твоего аккаунта)

1. https://github.com/Tilkerman/great-idea → **Settings** → **Pages**.
2. В поле **Custom domain** напиши: **tili.su** → Save.
3. Когда появится галочка DNS — включи **Enforce HTTPS**.

### Шаг 3. Напиши мне «DNS сделал»

Я пересоберу сайт под **tili.su** (без `/great-idea/` в адресе) и выложу. До этого сайт открывается как раньше:  
https://tilkerman.github.io/great-idea/

---

**Важно:** пока DNS не настроен, **tili.su** в браузере не откроется — это нормально.

## SSL и «Проверка DNS не удалась» (InvalidDNSError)

### Что должно быть в Reg.ru (проверено по ns1.reg.ru)

| Запись | Имя | Значение |
|--------|-----|----------|
| A | `@` | 185.199.108.153 |
| A | `@` | 185.199.109.153 |
| A | `@` | 185.199.110.153 |
| A | `@` | 185.199.111.153 |
| CNAME | `www` | `tilkerman.github.io` |
| AAAA | `@` | четыре адреса `2606:50c0:8000::153` … `8003::153` (см. шаг 1) |

На корне **не** должно быть CNAME — только A (+ AAAA). Лишние A на другие IP убери.

### Репозиторий

- Ветка **gh-pages**, в корне файл **CNAME** с одной строкой: `tili.su` (без `https://`).
- Settings → Pages → Custom domain: **tili.su** (не `www.tili.su`).

### Если в GitHub красная ошибка DNS, а записи как выше

1. Подожди 15–60 минут после правок в Reg.ru (TTL до суток).
2. На странице Pages нажми **«Проверьте ещё раз»**.
3. Не помогло: **очисти** поле Custom domain → Save → подожди 2–3 мин → снова введи `tili.su` → Save (так GitHub заново запрашивает сертификат).
4. Пока нет зелёной галочки DNS — **не** включай «Enforce HTTPS» (чекбокс серый — это нормально).
5. После галочки подожди **до 24 часов** (часто 15–60 мин): статус TLS «1 из 3» → готово. Тогда включи **Enforce HTTPS**.

Пока сертификат для `tili.su` не выдан, браузер может показывать предупреждение HTTPS или отдавать сертификат `*.github.io` — сайт по **http://tili.su/** при этом уже может открываться.

### Проверка с Mac

```bash
dig @ns1.reg.ru tili.su A +short
dig @ns1.reg.ru www.tili.su CNAME +short
```

Оба должны совпадать с таблицей выше.

### Если прошло больше суток, а в GitHub всё ещё InvalidDNSError

Снаружи DNS уже может быть **верным** (сайт открывается по `http://tili.su/`), а в Settings — красная ошибка: так бывает, проверка у GitHub «залипает».

1. Добавь **AAAA** в Reg.ru (шаг 4a), сохрани, подожди 30–60 мин.
2. Pages → **«Проверьте ещё раз»**.
3. Не помогло — [Support GitHub](https://support.github.com/contact): тема Pages, домен `tili.su`, приложи вывод `dig @ns1.reg.ru tili.su A +short` и скрин Reg.ru.
