# tili.su — что сделать на Reg.ru (простыми словами)

## Тебе — только Reg.ru и GitHub (я код и выкладку)

### Шаг 1. Reg.ru

1. Зайди на **reg.ru** → **Мои домены** → **tili.su**.
2. Открой **DNS-серверы / Управление зоной** (или «Ресурсные записи»).
3. **Удали** старые A/CNAME для `@` и `www`, если мешают (не трогай NS reg.ru, если домен на DNS Reg.ru).

4. **Добавь 4 записи типа A** (имя хоста **`@`** или пусто — «корень»):

   | Тип | Имя | Куда (значение) |
   |-----|-----|------------------|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |

5. **Добавь CNAME** для www:

   | Тип | Имя | Куда |
   |-----|-----|------|
   | CNAME | www | tilkerman.github.io |

6. Сохрани. Жди **от 15 минут до суток**.

### Шаг 2. GitHub (с твоего аккаунта)

1. https://github.com/Tilkerman/great-idea → **Settings** → **Pages**.
2. В поле **Custom domain** напиши: **tili.su** → Save.
3. Когда появится галочка DNS — включи **Enforce HTTPS**.

### Шаг 3. Напиши мне «DNS сделал»

Я пересоберу сайт под **tili.su** (без `/great-idea/` в адресе) и выложу. До этого сайт открывается как раньше:  
https://tilkerman.github.io/great-idea/

---

**Важно:** пока DNS не настроен, **tili.su** в браузере не откроется — это нормально.
