# TiLi: готовность к росту (PWA-first)

**Назначение:** один список «косяков и рисков на будущее» — что уже сделано в продукте/коде, что только задумано, что делать до рекламы и до N пользователей.

**Как читать статусы**

| Статус | Смысл |
|--------|--------|
| **Готово** | Уже в коде/проде, менять не обязательно для старта |
| **Частично** | Работает на малых масштабах; при росте нужна доработка |
| **Запланировано** | Решение принято, в коде ещё нет |
| **Риск** | Может сломаться или создать юридическую/репутационную проблему, если игнорировать |
| **Не делаем на этапе PWA** | Сознательно отложено (Play, Telegram-бот) |

**Этап:** только PWA, проверка спроса. Google Play и Telegram — не считаем.

**Прод:** https://tili.su/ (лендинг), https://tili.su/app/ (приложение). Push: Yandex Cloud Function + Object Storage. Аккаунт: `api.tili.su` (VPS AdminVPS, Германия).

**Обновлено:** 3 ноября 2026. oS3-чеклист в этот день не открывался.

## 1. Много пользователей (общее)

| Тема | Статус | Сейчас | Что может пойти не так | Когда чинить |
|------|--------|--------|------------------------|--------------|
| Данные задач | **Готово** | Гость — IndexedDB на устройстве. После входа снимок календаря и Lumi на `api.tili.su` | Рост аккаунтов упирается в VPS, не в Pages | Следить за диском/бэкапом VPS |
| GitHub Pages | **Готово** | Статика + Cloudflare Worker на tili.su | Лимиты Pages редко упираются для PWA | При смене домена — `BASE_PATH`, manifest, CORS push |
| Гость без аккаунта | **Готово** | Работает сразу локально | Снос PWA / очистка Safari = потеря дел | Онбординг уже говорит об этом |
| Регистрация и sync | **Частично** | Код и сервер есть; письмо подтверждения на бесплатном Unisender уходит только на `…@tili.su` | Gmail/Яндекс/Mail.ru «как будто не регистрируются» | **Блокер владельца:** тариф Unisender Go 6 000 писем / 800 ₽ в мес. |

## 2. Push-уведомления

| Тема | Статус | Сейчас | Что может пойти не так | Когда чинить |
|------|--------|--------|------------------------|--------------|
| Контур push | **Готово** | VAPID + API в prod-сборке, `subscribe` / `reminders` / `tick` | Нулевой баланс Yandex → push перестанут уходить | Следить за биллингом; пополнить до окончания гранта/баланса |
| UX «сначала настройки» | **Готово** | Первое напоминание → всплывашка; напоминания только при `notificationsEnabled` + permission | Пользователь ждёт push без настроек | — |
| iPhone | **Частично** | Только PWA с «Домой», iOS 16.4+ | Без установки push не будет (не баг) | Лендинг + onboarding текст |
| Android / «любая страна» | **Готово** | Географию TiLi не режет | Системные запреты, убитое приложение без облака | Облако уже есть; держать `tick` по расписанию |
| Время напоминания | **Частично** | `fireAt` считает **телефон** (мс), сервер сравнивает с `Date.now()` | Отдельного IANA timezone на сервере нет; смена пояса/ DST — edge cases | При жалobах или Lumi daily на сервере — хранить `timeZone` |
| Мёртвые подписки | **Готово** | 404/410 → устройство удаляется из `devices.json` | — | Можно логировать count для аналитики |
| **Масштаб push-сервера** | **Риск** | Все устройства в **одном** `devices.json`; каждый запрос read/write whole file; `sendDue` — цикл по всем | ~1000+ активных push: таймаут функции, гонки записи, задержки | **До** массовой рекламы с push: БД/очередь, sharding, idempotent writes |
| Стоимость | **Риск** | Pay-as-you-go Yandex | Рост вызовов `reminders` при каждом открытии app | Мониторинг расхода; лимиты частоты sync |
| CORS push API | **Готово** | Origins: `https://tili.su`, `www`, `tilkerman.github.io` | Новый домен без правки функции → subscribe fail | При ещё одном домене — добавить origin |
| Юридика UK/EU | **Риск** | Подписки push в Object Storage **РФ** | Реклама в UK/EU без adequacy / DPA | **До** рекламы UK/EU: юрист; опция EU endpoint для подписок |
| product-rules vs prod | **Готово** | Аккаунт и sync описаны в `product-decisions.mdc` | — | — |

## 3. Языки и реклама

| Тема | Статус | Сейчас | Что может пойти не так | Когда чинить |
|------|--------|--------|------------------------|--------------|
| UI ru / en / es | **Готово** | Каталог i18n, переключатель в настройках | Lumi: не везде es | По мере ES-рекламы |
| Default locale | **Частично** | Default **`ru`**, `index.html lang=ru` | Английская реклама без `?lang=en` → русский UI, пока человек сам не сменит язык | **До** EN-кампании: всегда давать ссылку с `?lang=en` |
| `?lang=` в URL | **Готово** | `appLocale.ts`: URL → сохранённый → браузер | PWA с Домой открывается без query | Кампании вести на `tili.su/app/?lang=en` |
| Лендинг RU/EN/ES | **Готово** | https://tili.su/ + `?lang=` | Нужны актуальные скрины, не placeholder | Перед рекламой переснять экраны |
| PWA `start_url` | **Риск** | `./` без `?lang=` | iPhone: отдельное хранилище от Safari; язык из вкладки не переносится | Manifest с lang **или** экран языка в standalone |

## 6. Пороги «когда что делать» (ориентир)

| Масштаб | Действие |
|---------|----------|
| **0 → нормальная регистрация** | Оплатить Unisender Go (иначе письма только на `@tili.su`) |
| **0 → первая реклама** | Ссылки с `?lang=en`, актуальные скрины лендинга, биллинг Yandex, юрист если UK/EU |
| **~100–300 push-устройств** | Смотреть логи `tick`, время выполнения функции, размер `devices.json` |
| **~1000+ push-устройств** | План миграции push-хранилища (не один JSON) |
| **UK/EU реклама** | Юрист + privacy; рассмотреть EU storage подписок |
| **Retention OK** | Тогда Google Play / Telegram-бот — отдельное решение |
