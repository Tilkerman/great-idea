# Голос + ИИ (TiLi)

## Поведение

- **Только TiLi:** на вкладке «Желания» (Lumi) «+» как раньше — новое желание, без голоса.
- **Короткое нажатие «+»** — новая задача (как раньше).
- **Удержание «+» ~0,4 с** — плюс → **микрофон**, подсказка «Говорите…», отпустить → разбор → **карточка дела** (сохранение вручную).

## Согласие

**Настройки → Данные → «Голосовые заметки с ИИ»** или диалог при первом удержании.

## Деплой бэкенда

1. Создай функцию в Yandex Cloud из `cloud/yandex/tili-voice-parse/` (как `tili-push`).
2. Переменные окружения:
   - `GROQ_API_KEY` — ключ [console.groq.com](https://console.groq.com)
   - `GROQ_MODEL` — по умолчанию `llama-3.1-8b-instant`
3. CORS origin: `https://tilkerman.github.io`
4. В `.env.production` сборки:
   - `VITE_VOICE_PARSE_URL=https://functions.yandexcloud.net/<id>`

Без URL и ключа: диктовка всё равно работает (Web Speech), текст попадает в карточку **без** разбора даты/категории через LLM.

## Микрофон

На iPhone — **PWA с «Домой»** и **HTTPS** (GitHub Pages). Разрешение микрофона запросит Safari при первой диктовке.
